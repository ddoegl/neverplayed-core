# Handover Ticket: Decoupled Philosophical Grounding & Naked Observer Fallback

*   **From:** Cognitive Architect
*   **To:** Development Engineer (dev)
*   **Context:** Currently, when switching between `idealist` and `realist` perspectives (which triggers a login), a "naked" session user (whose `tenantId` equals their `sessionId` or has no pre-registered surrogate) is automatically materialized as a `person` surrogate. This happens because the grounding shift fallback logic in `session-service` defaults the surrogate to `'person'` if `user.surrogateId` is falsy, and `person-registry` auto-provisions a `person` surrogate map on all active session users. Under the correct system ontology, perspective/grounding resides at the L1 identity (Being) level rather than the L6 surrogate (physical form) level. We want to support true "naked" observation where grounding shifts can occur at the identity level, defaulting to a system-appropriate `'observer'` surrogate if a surrogate is ever strictly required and there is no known initial surrogate, and falling back to a naked observer when transitioning into realms without recognized surrogates.

## Objectives

- [ ] **Provision `'observer'` Surrogate in Registry:**
    - Modify [surrogates.yaml](file:///Users/ddoegl/speckit/neverplayed/public/bundles/org.neverplayed.being-service/data/surrogates.yaml) to register the `'observer'` surrogate:
      ```yaml
      - id: observer
        label: Observer
        senses:
          - Language
      ```

- [ ] **Store Grounding on L1 Identity Level in Session Service:**
    - Update [session-service/activator.js](file:///Users/ddoegl/speckit/neverplayed/public/bundles/org.neverplayed.session-service/activator.js):
        - In `shiftGrounding(targetGrounding, scope)`:
            - Always set the root grounding property: `this.scopedUsers[targetScope][user.id].grounding = targetGrounding`.
            - Perform a re-login using the current active surrogate (or `null` if naked): `this.login(user.id, targetScope, activeSurrogate)`. Do NOT default to `'person'`.
        - In the `currentUser` getter & `_materialize(identity)`:
            - Expose `grounding` on the root of the returned user profile (defaulting to `'idealist'`), regardless of whether `activeSurrogateId` is active or null.
        - In `login(user, scope, surrogate)`:
            - Allow logins where `surrogate = null` while preserving and propagating the L1 identity's root `grounding` state.

- [ ] **Align Perceiver Service Context Sync:**
    - Update [perceiver-service/activator.js](file:///Users/ddoegl/speckit/neverplayed/public/bundles/org.neverplayed.perceiver-service/activator.js):
        - In `_syncFromSession(session)`:
            - Fetch `grounding` directly from the L1 root user object (`user.grounding || 'idealist'`) instead of looking inside the `surrogate` state, and map it directly to the perceiver's active perspective context.

- [ ] **Update Realm Manager Transitions to Decouple Fallback:**
    - Update [realm-manager/activator.js](file:///Users/ddoegl/speckit/neverplayed/public/bundles/org.neverplayed.realm-manager/activator.js):
        - In `_executeTransition` and `_switchRealm`:
            - If the user's active surrogate is recognized by the destination realm's manifest `recognizedSurrogates`, keep it.
            - Otherwise, if the user possesses *any* recognized surrogate for that realm, auto-materialize it.
            - Otherwise, deactivate any active surrogate and transition the being as a **naked observer** (`activeSurrogate = null`).

- [ ] **Verification:**
    - Run the existing test suite: `deno test -A --import-map=tests/test_import_map.json tests/run-all.ts`
    - Add a unit test verifying that shifting grounding on a surrogateless user updates their perspective without materializing them as a `person`.
