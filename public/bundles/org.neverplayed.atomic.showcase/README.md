# 🛡️ Atomic Showcase Bundle
![Documentation Health](https://img.shields.io/badge/Documentation-Stable-green)


Demonstration of the NPRF Atomic Flow engine and core semantic capabilities.

## 🏛️ Architecture & Implementation

- **Sample Flows**: Implementation of various multi-step journeys (Retail, Business).
- **Inhabitant Showcase**: Visual demonstration of how inhabitants render within the Shell Host.

## 🏛️ The Patterns (The State)

- **[Platform Alignment](../../docs/platform-patterns.md)**: Implements **Non-Destructive Rendering** (Pattern 17/ADR-0008) and **Multi-Phase Boot** (Pattern 14/ADR-0014).
- **[ADR-0008: Focus Preserving Rendering](../../docs/adr/0008-focus-preserving-rendering.md)**: Demonstrates the Atomic UI's ability to maintain focus and state during complex transitions.
